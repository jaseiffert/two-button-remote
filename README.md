# garage-lights-remote

Things you need to change.
- WiFi SSID and Password
- In the Loop Button checks you need to change the IP Address of your Tasmota device.
- If you used a Common Cathode LED instead of the Common Anode I do, you will need to change the HIGH to LOW and LOW to HIGH for the LED DigitalWrite

For the Hardware assembly and 3D printed case go here: https://www.thingiverse.com/thing:7024483
